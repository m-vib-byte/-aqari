# AQARI V187 — Integration Bridge

هذه النسخة تنقل عقاري من مجرد واجهة إلى حزمة قابلة لاختبار الربط الإنتاجي على Vercel.

## Endpoints
- `/api/health` — صحة الخدمة.
- `/api/release` — رقم الإصدار وبيانات النشر.
- `/api/config-status` — يبين وجود متغيرات البيئة فقط، بدون كشف أي أسرار.

## قبل الإنتاج
1. ارفع المشروع على فرع Preview.
2. أضف متغيرات البيئة في Vercel.
3. افتح `/api/config-status` وتأكد أن `ready=true`.
4. شغّل Smoke Test على رابط الـPreview.
5. بعد نجاح الاختبارات فقط ادمج إلى `main`.

هذه النسخة لا تنشئ قاعدة البيانات ولا تربط مزود الدفع/واتساب/البريد تلقائيًا؛ هي جسر اختبار وربط آمن للمرحلة التالية.
