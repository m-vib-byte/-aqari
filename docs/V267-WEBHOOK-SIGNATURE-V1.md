# توقيع Webhook — AQARI V267

هذا بروتوكول المحول الخادمي العام، وليس توثيقاً لبروتوكول K-Net أو إعلان تشغيل أي مزود. يلزم محول يتحقق من توقيع المزود الرسمي قبل إنشاء هذا الغلاف؛ لا يقبل توقيعاً قديماً لا يحمي معرّف الحدث.

الرسالة الموقعة هي بايتات UTF-8 التالية، بفاصل LF واحد، ثم محتوى HTTP الخام كما وصل دون إعادة تسلسل JSON:

```text
aqari-webhook-v1\n
<workspace UUID lowercase>\n
<provider>\n
<x-aqari-timestamp>\n
<x-aqari-event-id>\n
<raw body bytes>
```

عرض `\n` يوضح الفاصل فقط: لا تضاف أسطر فارغة بين الحقول. تطبق HMAC-SHA256 بمفتاح خادمي لا يقل عن 32 حرفاً، ثم ترسل النتيجة بصيغة hex صغيرة من 64 خانة في `x-aqari-signature`. أسماء المفاتيح موجودة في `secret_name`، ولا ترسل إلى المتصفح.

يلزم توقيت Unix بالثواني ضمن ±300 ثانية، ومعرّف حدث ثابت لكل إعادة محاولة. الحقول الموقعة تشمل مساحة العمل والمزود ومعرّف الحدث لمنع نقل توقيع صحيح إلى مسار أو مفتاح منع تكرار آخر. يرفض JSON المكرر المفاتيح والأعداد غير المحدودة. يقبل إعادة التسليم المطابقة ليعيد دفتر قاعدة البيانات النتيجة السابقة دون مضاعفة الأثر.

الاختبارات المحلية تغطي التوقيع الصحيح، تبديل المحتوى والوقت والمزود والمساحة ومعرّف الحدث، التوقيع القديم، انتهاء المهلة، وفقد المفتاح. هذا لا يثبت إرسال مزود حقيقي، ولا تحويل حدث الدفع إلى تحصيل أو وصل إيجار. لا تغيير للمفاتيح الحالية أو حسابات المستخدمين في هذا الإصلاح.
