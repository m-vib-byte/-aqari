هذه أدلة برمجية وSQL بهويات اصطناعية؛ لا تثبت تسجيل دخول أو AAL2 أو توقيعًا أو تسليم بريد أو تنزيل بايتات Storage أو جهازًا فعليًا. نتيجة بناء رابط التجريبي وفحوص GitHub تُقرأ للالتزام المنشور نفسه، ولا تُستنتج من الاختبارات المحلية.
