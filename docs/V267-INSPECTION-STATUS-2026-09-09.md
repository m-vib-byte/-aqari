# تقرير حالة فحص MyAqari V267 — ٩ سبتمبر ٢٠٢٦

**النتيجة: غير جاهز للاعتماد النهائي.** هذا تقرير بالأدلة المتاحة والنواقص، وليس شهادة اكتمال أو تقرير نجاح لجميع الوظائف. يستمر حظر النشر إلى Production وتغيير الدومين أو V266 حتى اعتماد المالك النهائي.

## تحديث لاحق في اليوم نفسه — عزل الشريك

أصبح عزل الشريك حسب العقار منفذًا في قاعدة Staging، مع شاشة للمدير لمنح وسحب الوصول، وبوابة شريك مستقلة بخمس لغات. نجح اختبار SQL بحسابين وعقارين ومبالغ مختلفة لشهرين، بما يشمل رفض الوصول المتبادل والبيانات الخام وواجهات الإدارة، سحب الصلاحية، منع عضوية موظف عامة، وحفظ مساري إنشاء حساب الموظف والمستأجر. نجحت ٥٣٢ تجربة Node محلية، منها عشرة اختبارات جديدة لحدود جلسة الشريك. التفاصيل في [تقرير عزل الشريك](V267-PARTNER-ACCESS.md).

هذا يُحدّث وصف «غير منفذ» أدناه إلى «منفذ ومختبر في SQL، وينتظر الفحص النهائي بحساب شريك فعلي». لم يُنشأ حساب شريك حقيقي أو تُمنح صلاحية دائمة لأحد؛ جرى التراجع عن بيانات الاختبار بالكامل. بقية نواقص الاعتماد المذكورة أدناه ما زالت قائمة.

## مراجع برج شيخة الناقصة تحديدًا

استنادًا إلى تقرير `Shaikhah-Reconciliation.md` المؤرخ ٨ سبتمبر، تبقى ثلاث نقاط مصدرية مفتوحة، ولا يلزم إعادة طلب كشف شيخة كله:

1. **التأمين:** مجموع التفاصيل ٢٬٤٥٠ د.ك مقابل ملخص ٢٬٢٠٠ د.ك. المطلوب سجل التأمين التفصيلي أو اعتماد محاسبي للقيمة لكل وحدة.
2. **الوحدتان ٤٠٢ و٤٠٣:** البداية المسجلة ٢٠٢٤/١٠/٠١ والنهاية ٢٠٢٤/٠٩/٣٠. المطلوب صفحات التواريخ من العقدين الموقعين أو بيان معتمد يصححها.
3. **الوحدة ٧٠٣:** دفعة بتاريخ ٢٠٢٥/٠٨/٠٢ في كشف أغسطس ٢٠٢٦، وصل ١٠٦٩ ومعاملة ٤٢٩٥٠٨. المطلوب إثبات الدفعة الأصلي لتأكيد التاريخ والفترة.

يلزم عقد موقع وإثبات دفع فعلي لاعتماد أول دورة عقد وتحصيل وإيصال. الوصل الفارغ ١١٣٠ لا يُعامل كإثبات دفع. لم يحدد البحث المتاح حتى الآن المصدر الكامل المعتمد لبيانات ضحاوي؛ لا يجوز اعتبار ملفات مشتقة أو قديمة بديلًا معتمدًا عنه.

## البنود المتبقية قبل الاعتماد

1. **استعادة تشغيل CI وفحص آخر نسخة:** تحديد سبب التوقف قبل التنفيذ من تنبيهات GitHub Actions، ثم نجاح مسارات التشغيل، الدخول، الاستعادة، الظهور الأول، الصفحة الرئيسية، E2E وبوابة الإصدار على نفس النسخة المرشحة.
2. **التحقق بالحسابات والأجهزة:** دخول، تحديث الصفحة، تنقل، انتهاء جلسة، خروج ودخول مجددًا؛ فحص المدير والمستأجر والحسابات ذات الصلاحيات المحدودة، مع إعادة قراءة النتائج من القاعدة المعزولة. الحسابات المطلوبة ليست جميعها موجودة حاليًا.
3. **إكمال دورة إعادة تعيين كلمة المرور:** الصفحة الحالية لاستعادة البيانات ليست واجهة إعادة تعيين كلمة المرور؛ يلزم التحقق من رابط الاستعادة وواجهة تعيين كلمة المرور الجديدة والدخول بعدها دون كشف بيانات قبل التأكد من الجلسة.
4. **مطابقة بيانات المصدر:** معالجة النقاط الثلاث المحددة لشيخة، وتحديد مصدر ضحاوي المعتمد قبل استيراده؛ منع اعتماد قيم تخمينية أو تحويل المسودات إلى عقود نافذة دون المستندات.
5. **فحص معاملات الأعمال فعليًا:** مراجعة واعتماد العقد، إرفاق وقراءة المستند، تسجيل الدفعة، إصدار وفتح الإيصال، الخدمات والصيانة والمرافق وكشوف الحساب؛ اختبار الفشل والانقطاع وإعادة المحاولة ومنع التكرار، ثم مطابقة السجلات والتقارير.
6. **عزل صلاحيات الشريك بالعقار:** إكمال نموذج الصلاحيات والتحقق من قاعدة البيانات والواجهات والتنزيلات بحسابين وعقارين مختلفين. وجود واجهة الشركاء لا يثبت منع قراءة عقار غير مخول.
7. **الأجزاء القديمة والتكاملات:** إكمال تغطية اللغات والمسارات القديمة المطلوبة، وتكوين المجدول وقناة الإشعارات المعتمدة والتحقق من التسليم ومنع التكرار. صفحة حالة الأتمتة الحالية تصرح بعدم وجود مجدول أو مرسل مهيأ؛ لا يوجد دليل على إرسال خارجي فعلي.
8. **حزمة الفحص النهائية:** تثبيت نسخة واحدة مع رابط معاينة صالح، نتائج اختبارات مرتبطة برقمها، سجل العيوب وإغلاقها، ومطابقة البيانات واختبار الاسترجاع؛ ثم تقديمها لاعتماد المالك.
