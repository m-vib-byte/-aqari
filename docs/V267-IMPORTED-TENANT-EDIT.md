# V267 — تعديل المستأجر المستورد
Staging only: djkpkkgoibruaezdrchb. لا تعديل V266 أو Production أو myaqari.com.

## ما تغير
يفتح تعديل المستأجر المستورد نافذة مستقلة تقرأ الملف الحالي من قاعدة البيانات، وتسمح للمدير العام بتعديل الاسم العربي/الإنجليزي والمدني والهاتف والبريد والجنسية والعنوان. يكفي اسم واحد، وتبقى الحقول غير المتوفرة فارغة. يجب أن تكون القيم المدخلة صحيحة. حفظ المسودة المعتمد باقٍ.

يلزم سبب تعديل بين 3 و500 حرف. كل حفظ يسجل هوية المنفذ والوقت والقيم السابقة والجديدة في سجل خاص. تظهر آخر 10 تغييرات في النافذة. يحافظ الحفظ على sourceValues وsourceReference وimport_source، وعلى العقود والوصول والمدفوعات التاريخية. تُحدَّث قائمة المستأجرين ودليل الاتصال وتُزال مسودة الملف بعد الحفظ الناجح.

تغيير بريد مرتبط بحساب فعلي يُرفض حتى يتم التحقق من هوية صاحب الحساب بإجراء مستقل. لا يمنح هذا المسار حساباً أو صلاحية جديدة ولا يصحح كشوف المصدر أو مبالغها.

## السلامة
وظيفتا API عامتان SECURITY INVOKER تستدعيان تنفيذًا خاصًا يتحقق من المدير والصلاحية والمساحة. سجل التعديلات الخاص محمي بـRLS ومنع الوصول المباشر. القفل ورقم مراجعة مساحة العمل يمنعان الكتابات المتزامنة القديمة. يمنع تمرير حقول المصدر والهوية والربط. تُعاد قراءة السجل بعد الحفظ قبل إعلان النجاح؛ فشل الاتصال يمنع إعادة الإرسال قبل تحديث الملف.

## دليل الفحص
- SQL مباشر على Staging، مع مستخدم مدير ومحاسب اصطناعيين: تعديل ملف مستورد، إعادة القراءة، تاريخ قبل/بعد، بقاء المصدر والعقود، رفض مراجعة قديمة، رفض تغيير المصدر، رفض قراءة/كتابة المحاسب. انتهى الاختبار بـROLLBACK؛ لا تصحيح فعلي لبيانات الملاك.
- اختبار واجهة مستقل: تحديث رقم المراجعة بعد المسودة، ثم حفظ موثق؛ ومنع تكرار الإرسال بعد نتيجة غير مؤكدة.
- 557 اختبارات Node ناجحة، صفر فشل/تخطي.
- مستشار الأمان لم يُظهر ملاحظة جديدة لهذا المسار؛ التحذيرات السابقة ليست مغلقة بهذا الإصلاح.
- فحص متصفح بالحساب الحقيقي لهذا المسار واختبارات iPhone/iPad الفعلية لم تُنفذ بعد. CI مستقل ومعلق؛ لا ادعاء Release Gate ناجح.
