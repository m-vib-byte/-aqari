# إعادة تعيين كلمة المرور — V267، ٩ سبتمبر ٢٠٢٦

التعديل على فرع المعاينة وPR #69 فقط. لا تغيير لـ Production أو myaqari.com أو V266، ولا لإعدادات Auth أو قالب البريد أو عناوين الرجوع المعتمدة.

## التنفيذ

- يصل رابط الاستعادة الحالي إلى عنوان login.html المعتمد. يوجّه رابط type=recovery وأخطاء callback في fragment إلى reset-password.html قبل تشغيل الاتصال أو استعادة جلسة الإدارة. يبقى الدخول العادي على مساره الأصلي.
- تعرض صفحة مستقلة نموذج كلمة المرور الجديدة وتأكيدها باللغات الخمس. لا تقرأ بيانات الأعمال أو العضويات، ولا ترسل بريدًا تلقائيًا.
- تستخدم مكتبة Supabase المثبتة 2.114.0 وجلسة في الذاكرة فقط، بمفتاح منفصل، دون تخزين دائم أو تجديد تلقائي. لا تقبل جلسة عادية بدل حدث PASSWORD_RECOVERY. يتحقق الخادم من المستخدم قبل إتاحة النموذج وقبل التعديل وبعده.
- تُحذف قيم حقول كلمة المرور عند بدء الحفظ أو فقد الجلسة. تزال بيانات callback من عنوان الصفحة بعد استهلاك المكتبة لها سواء نجح التحقق أو فشل، مع سياسة no-referrer. لا تُسجل الرموز أو رسائل المزود الخام.
- المهلة تشمل انتظار المصادقة والشبكة وجسم الاستجابة. الخروج أو تبديل الحساب أو مغادرة الصفحة يبطل العملية ويوقف الطلبات اللاحقة. النتيجة غير المؤكدة تمنع إعادة الحفظ في الصفحة نفسها؛ يُطلب تجربة الدخول أو رابط جديد.
- بعد تحديث مؤكد يطلب التطبيق تسجيل الخروج العام. فشل هذه الخطوة يظهر منفصلًا عن نجاح حفظ كلمة المرور. لا يعني تسجيل الخروج إبطال JWT الصادر فورًا؛ تبقى حدود انتهاء access token الخاصة بـSupabase سارية.
- المسار يدعم callback الضمني الحالي. لا يضيف تدفق PKCE أو OTP أو يغيّر سياسة البريد. إعادة تحميل صفحة الاستعادة بعد إزالة الرابط لا تستعيد جلسة الاستعادة؛ يلزم رابط جديد صالح.
- صفحة الدخول 16,965 بايت، تحت حد الفحص 17,000، وCSS الأصلي محفوظ. تقليل حجم JavaScript اقتصر على فواصل الأسطر.

## التحقق وحدوده

أضيف 13 اختبارًا تغطي حدث الاستعادة المؤجل، رفض الجلسة العادية أو المفقودة، مطابقة كلمة المرور وطولها، الخروج أثناء التحقق، تغيير الحساب، الحفظ غير المؤكد وعدم تكراره، أخطاء المزود، فشل إنهاء الجلسات، مغادرة الصفحة، استجابة 204 الفارغة، تعليق جسم الاستجابة، وتوجيه رابط الاستعادة قبل تشغيل الدخول العادي.

هذه اختبارات محلية بعميل وطلبات اصطناعية؛ ليست دورة بريد حقيقية ولا تغييرًا لكلمة مرور الحساب الفعلي. يتطلب إغلاق البند نهائيًا اختبار رسالة الاستعادة بحساب فعلي، والرابط المنتهي والمستخدم سابقًا، وحفظ كلمة المرور ثم الدخول بها على جهاز المستخدم. يبين وصف PR نتيجة الفحص الكلي ونشر المعاينة وCI والفحص الحي لهذا التعديل.
