# V267 rental contract logo

Adds the existing aqari-icon.svg gold house logo and Arabic AQARI wordmark
above each rendered contract and annex. The same heading appears in draft
previews and both approved printed sets. The image is embedded as a data URI,
so exported HTML and blob print documents do not depend on an external image
request. A compact 56px image, Arabic alternative text, restrained gold divider
and unbroken heading preserve legibility in the existing RTL document.

No clauses, contract values, approval rules, signatures or saved records change.
Existing authoritative contract-print tests pass. This is a Preview change;
physical print/device acceptance and full-155 completion are not claimed.
